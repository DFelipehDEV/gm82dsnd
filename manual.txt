

    Game Maker 8.2 DirectSound
    ==========================
    v0.1
    3 Sep 2026


  A modern audio engine for Game Maker 8.2.
  
  Requires Core and Buffer.


-------------------------------------------------------------------------------

  Preamble
  --------

  This extension was designed from the ground up using native DirectSound
  technology to be the definitive Game Maker 8.2 game audio solution.
  
  While not as powerful as 8.2 Sound, this extension is much smaller and
  faster, using up only about 25 KB of exe space when compared to FmodEx's
  vast 760 KB, with much less code running per frame and per function call,
  leading to better game size, load times and performance.
  
  Additionally, just like how it's done in the Audio extension, in-memory sound
  resource handling allows for sound organization in the 8.2 IDE, while also
  negating the long load times associated with loading sounds from disk at game
  start.
  
  Finally, we've added even more quality of life features, such as the concept
  of persistent sounds, the ability to rename sounds, clearer error messages,
  and other goodies from Sound and Audio such as .wasd sound packs, adding
  sounds from included files, referring to sounds as either strings or indexes,
  music layering and fading, configurable extension behavior, and much more.


-------------------------------------------------------------------------------

  Settings
  --------

    Some of the things Game Maker's audio engine does are a little odd.
    This extension changes some of those behaviors, but if your project has
    existing code that relies on the vanilla quirks, you can disable these
    settings to restore that kind of behavior.


- sound_settings(setting,value)
    Changes extension configuration. All settings are on by default.
    Turning all settings off emulates vanilla Game Maker behavior.
    
  - dsound_use_linear_volume
      Game Maker's volume scale is a logarithmic attenuation value, from 30
      to 100, where half loudness is somewhere around 85, and 60 is inaudible.
      Our extension instead uses a more intuitive linear volume scale where
      50 is half as loud, and 0 is inaudible. If your project uses logarithmic
      volume, you can disable this option to restore the vanilla volume scale.

  - dsound_use_scheduler
      Game maker sound functions act immediately upon call. Sometimes this is
      undesirable, such as when you want to play a sound and then immediately
      change the settings for it somewhere else within the same frame - if your
      game is laggy, you could hear a spike as the sound plays at full volume
      for a very short period of time.
      In order to mitigate this, our extension uses a system where newly played
      sounds and changes to sound instances are only executed once per step,
      in a way where sound operations are more consistent and predictable.
      Turning this option off will instead apply sound operations immediately.

  - dsound_reuse_sound_ids
      Normally, Game Maker assigns incrementing ids to newly added sounds,
      but this means you will eventually run out of space for sounds at
      100000 where our extension's instance ids start.
      Here we provide an option to reuse dead sound indexes for newly added
      resources. If your code is not designed to handle that, you can disable
      this option to use incrementing ids only and leave deleted sounds
      permanently deleted. Additionally, sound resource id 0 is never used.

  Background Music
  ----------------
  
    We provide some convenience functions to make managing background music
    a little easier. Additionally, it is possible to have more than one layer
    of background music playing at the same time, using the layer function.


- sound_background_instance()
    Returns the instance id of the currently playing background music,
    or noone if there isn't one. If there are multiple layers of music
    currently active, the function returns the newest one.
    To get a list of all active background music layers,
    use sound_kind_instance_list(kind_background).

- sound_background_tempo(value)
    This function is not currently available due to no MIDI support.

- sound_background_crossfade(index,time,volume,pan,pitch,loop)
    Crossfades between two background music tracks over a specified time.

- sound_background_switch(index,time,volume,pan,pitch,loop)
    Fades out the current background music then fades in the new one.

- sound_background_layer(index,vol,pitch,pan,loop)
    Adds a new layer of background music.


-------------------------------------------------------------------------------

  Sound Persistence
  -----------------
  
    In order to solve the common problem of looping sounds remaining after
    leaving a room, we have a new sound persistence system. Only sounds that
    have the persistent flag are allowed to remain playing between rooms.

  
- sound_set_persistent(index,persistent)
    Makes a sound index or instance persistent. When a sound is persistent,
    all instances created from that sound will be persistent too.

  Getters and Setters
  -------------------

    All getters and setters accept either sound resources or instance ids.
    Any sound-only properties, when queried on instances, will instead return
    the property for the sound resource of which the instance is from -
    for example, instances do not have a 'preload' attribute.
    
    Additionally, new logic is used when deciding the properties of instances.
    
    Usually, when you change the volume or pitch value of a sound resource,
    any changes to an instance of that sound would simply override it.
    To mitigate this, instance properties are now combined with those of the
    sound resource of which it is an instance of, as well as the settings for
    the 'kind' of the sound.
    
    For example, if a sound resource has the following properties:
    
    - volume:  0.5
    - pitch:   0.9
    - pan:    -0.1
    
    and the kind of the sound is set to the following:
    
    - volume:  0.75
    - pitch:   1.0
    - pan:     0.0
    
    and the instance has the following properties:
    
    - volume:  0.8
    - pitch:   0.5
    - pan:     0.3
    
    then the resulting sound coming out of the mixer would be:
    
    - volume:  0.5 * 0.75 * 0.8 = 0.3
    - pitch:   0.9 * 1.0  * 0.5 = 0.45
    - pan:    -0.1 + 0.0  + 0.3 = 0.2
    
    
    This system allows for developers to set baseline values on a sound
    resource for mastering purposes, and then have each instance of that sound
    behave in a predictable way without having to go around and change values
    everywhere in your code that deals with instances. The overall experience
    is much more intuitive and convenient.

  Sound Kind Operations
  ---------------------
  
    In addition to normal operation, it is also possible to batch-operate on
    all sounds of a specific kind. For example, you may want to stop all
    kind 0 sound effects, or change the volume of all kind 1 music tracks.
    The kind functions allow you to perform such actions.


- sound_kind_volume(kind,volume)

- sound_kind_pan(kind,pan)

- sound_kind_pitch(kind,pitch)

- sound_kind_pause(kind)

- sound_kind_resume(kind)

- sound_kind_stop(kind)

- sound_kind_instance_list
